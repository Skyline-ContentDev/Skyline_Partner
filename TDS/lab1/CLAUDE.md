# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is an **HTML5 interactive e-learning module** ("Lab 1a") generated by **ActivePresenter 10.1.2** for TD Synnex OT Network Assessment training. It runs entirely in the browser with no build step.

## Running the Project

Open `practice.html` directly in a browser. No server required for basic viewing; if audio/video fails due to MIME types, serve from a local HTTP server:

```powershell
# Python simple server (if available)
python -m http.server 8080
# Then open http://localhost:8080/practice.html
```

The `.htaccess` file handles MIME types for Apache deployments (m4a, mp4, etc.).

## Architecture

The player is initialized in `practice.html` via:
```javascript
AtomiAP.open("rlprez.js", "lqMz5QfJ", { playMode: "Practice", ... })
```

| File | Role |
|------|------|
| `practice.html` | Entry point; loads all scripts and seeds the player container |
| `rlprez.js` | All presentation content — slides, questions, feedback, styling params — as a minified data object |
| `rlprez.css` | Presentation-specific CSS (hotspot animations, dropdowns, layout) |
| `player/rlplayer.js` | Core engine (719 KB); includes embedded jQuery 3.6.0; handles rendering, interactions, scoring, timeline |
| `player/rlplayer.css` | Framework UI styling (sidebar, toolbar, controls) |
| `player/rlplayer.lang.en-US.js` | UI string translations |
| `resources/` | Static assets: PNG images (`res_10001–10071`), M4A audio (`res_10083–10096, res_131`), JPG thumbnails (`thumb_77–111`) |

## Content Data Structure (`rlprez.js`)

This file is the **only file you should edit** to change presentation content. It is a minified JS file that calls into the player engine. Key top-level fields:

- `projectName` / `author` / `language` — metadata
- `l` — canvas dimensions `[[1920, 1080]]`
- `params` — UI configuration for 4 modes: `[Demo, Practice, Tutorial, Test]` (array index = mode index)
- `feedbacks` — named feedback screens: `"Correct Feedback"`, `"Incorrect Feedback"`, `"Try Again Feedback"`, `"Complete Feedback"`, `"Incomplete Feedback"`, `"Timeout Feedback"`, `"Resume Feedback"`
- `cc` — slide content containers with nested interactive elements (buttons `c:6`, text inputs, images, hotspots)

## Play Modes

The player supports four modes controlled by the `playMode` parameter in `practice.html`:

| Mode | Description |
|------|-------------|
| `"Practice"` | Default; allows retries, shows feedback |
| `"Test"` | Scored assessment |
| `"Demo"` | Auto-play walkthrough |
| `"Tutorial"` | Guided step-by-step |

## Editing Guidance

- **`player/rlplayer.js`** — Do not edit; third-party engine generated by ActivePresenter.
- **`rlprez.js`** — Minified; edit with caution. Changes to slide/question data require understanding the nested `cc[]` structure and style index references.
- **`rlprez.css`** — Safe to edit for presentation-level style tweaks. Key classes: `.ap-hotspot` (pulsing clickable zones), `.ap-prez-container` (main wrapper), `.ap-focused` (keyboard nav indicator).
- **Resource files** — Referenced by index (`res_10001.png`, etc.); renaming breaks references in `rlprez.js`.

## Deployment

- **Static hosting**: Drop the entire folder onto any web server.
- **Apache**: `.htaccess` is already configured for audio/video MIME types.
- **No CDN dependencies** — all assets are local; this works offline.
